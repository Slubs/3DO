# Руководство по компиляции через GitHub Actions

Этот проект настроен для автоматической компиляции через GitHub Actions. Это означает, что вы можете скомпилировать ядро для Android (и других платформ) без установки каких-либо инструментов локально.

## Быстрый старт

### Шаг 1: Загрузите проект на GitHub

1. Создайте репозиторий на GitHub (если ещё не создан)
2. Загрузите файлы проекта в репозиторий

### Шаг 2: Запустите компиляцию

1. Перейдите на вкладку **Actions** в вашем репозитории на GitHub
2. Выберите workflow **"Multi-Platform Build"**
3. Нажмите кнопку **"Run workflow"**
4. Выберите ветку (обычно `main` или `master`)
5. Нажмите **"Run workflow"**

### Шаг 3: Скачайте результат

1. Дождитесь завершения компиляции (5-15 минут)
2. Нажмите на успешный запуск (зелёная галочка)
3. В разделе **"Artifacts"** скачайте нужный файл:
   - `opera_libretro_android_arm64` - для современных Android устройств
   - `opera_libretro_android_armv7` - для старых Android устройств
   - `opera_libretro_windows` - для Windows
   - `opera_libretro_linux` - для Linux

## Установка в RetroArch на Android

1. Распакуйте скачанный архив
2. Скопируйте файл `opera_libretro.so` в папку:
   ```
   /Android/data/com.retroarch/files/cores/
   ```
3. Или используйте файловый менеджер на Android для копирования

## Доступные workflow файлы

### `all-platforms-build.yml` (рекомендуется)
Собирает ядра для всех платформ:
- Android ARM64 (arm64-v8a)
- Android ARMv7 (armeabi-v7a)
- Windows (x64)
- Linux (x64)

### `android-build.yml`
Собирает ядра только для Android.

## Триггеры компиляции

Компиляция запускается автоматически при:
- **Push** в ветки `main` или `master`
- **Pull Request** в эти ветки
- **Ручном запуске** через вкладку Actions

## Время компиляции

| Платформа | Время |
|-----------|-------|
| Android ARM64 | ~5-8 минут |
| Android ARMv7 | ~5-8 минут |
| Windows | ~3-5 минут |
| Linux | ~2-4 минуты |

## Устранение проблем

### Ошибка: "Repository not found"
Убедитесь, что репозиторий существует и у вас есть доступ.

### Ошибка: "Workflow not found"
Убедитесь, что файлы workflow находятся в `.github/workflows/`

### Ошибка компиляции: "No such file or directory"
Проверьте, что все исходные файлы загружены в репозиторий.

### Ошибка: "NDK not found"
Workflow автоматически устанавливает NDK через `nttld/setup-ndk@v1`. Убедитесь, что этот action доступен.

## Хранение артефактов

Артефакты хранятся **30 дней** после компиляции. Для постоянного хранения создайте **Release** на GitHub.
